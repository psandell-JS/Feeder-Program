OMRON PLC LADDER LOGIC PROGRAM
ENCODER-SYNCHRONIZED CARD FEEDER SYSTEM
For Omron CP1H-X40DT-D with CX-Programmer
=============================================================================

PROGRAM NAME: Card_Feeder_Encoder_Sync_v2.0
DATE: 2026-02-03
CONTROLLER: CP1H-X40DT-D
APPLICATION: Position-controlled card feeding onto moving paper

HARDWARE:
- Encoder: Accu-Coder 3032091 (paper position tracking)
- Start Sensor: Banner SME312D (paper detection)
- Stop Sensor: Optex 15PL (card ready at tip)

SECTION 4: PAPER DETECTION AND POSITION CALCULATION (Rungs 33-47)
=============================================================================

RUNG 33: Detect Paper with Start Sensor
|--[ 0.03 ]------[ W0.03 ]------[ W0.00 ]------[ NOT W0.06 ]--( SET W0.04 )--|
|  (START_SENSOR) (CARD_READY) (SYSTEM_RUN) (NOT FEEDING)   (PAPER_DETECTED)|
|  Start sensor AND card ready AND running AND not feeding = Paper detected   |

RUNG 37: Log Start Position When Paper Detected
|--[ @W0.04 ]--------------------------------------[MOV(021)]--|
|  (PAPER_DETECTED rising edge)                 Source: D0      |
|                                                Dest: D100      |
|  Save encoder position when paper detected                    |

RUNG 38: Calculate Target Feed Position
|--[ @W0.04 ]--------------------------------------[ADD(401)]--|
|  (PAPER_DETECTED rising edge)                 Aug: D100       |
|                                                Add: D2         |
|                                                Result: D6      |
|  TARGET = START_POSITION + FEED_DELAY_COUNTS                  |

RUNG 39: Alternative - Use Fixed Delay Mode (If Preferred)
|--[ @W0.04 ]------[ 0.12 ]------------------------@TIM005 15#XX--|
|  (PAPER_DETECTED) (DELAY_MODE_SELECT)        (Delay timer)     |
|  Instead of position, use time delay if encoder not used       |
|  Set timer preset based on belt speed                          |

RUNG 40: Compare Current Position to Target
|--[ W0.04 ]------[ NOT W0.05 ]-------------------[CMP(020)]--|
|  (PAPER_DETECTED) (NOT TRIGGERED)             Compare Mode: ≥ |
|                                                Data1: D0       |
|                                                Data2: D6       |
|                                                Result: W10.00  |
|  Check if current encoder position ≥ target position          |

RUNG 41: Trigger Feed When Position Reached
|--[ W0.04 ]------[ W10.00 ]----------------------( SET W0.05 )--|
|  (PAPER_DETECTED) (POSITION_REACHED)         (FEED_TRIGGER)   |
|  Position reached = Trigger feed                               |

RUNG 42: Alternative Time-Based Trigger
|--[ W0.04 ]------[ TIM005 ]------[ 0.12 ]--------( SET W0.05 )--|
|  (PAPER_DETECTED) (TIMER DONE) (DELAY_MODE)  (FEED_TRIGGER)   |

=============================================================================
DATA REGISTER DEFAULT VALUES (Set via CX-Programmer)
=============================================================================

D0  = 0         ; Current encoder position (updated continuously)
D1  = 1000      ; Target position (calculated)
D2  = 500       ; Feed delay counts (ADJUST DURING CALIBRATION)
D3  = 0         ; Cycle counter
D4  = 0         ; Fault counter
D5  = 2000      ; Encoder PPR (pulses per revolution)
D6  = 0         ; Calculated feed position
D7  = 0         ; Last feed position (diagnostic)
D50 = 0         ; Previous encoder position (speed calc)
D51 = 0         ; Encoder speed (counts per scan)
D100 = 0        ; Start sensor trigger position

=============================================================================
NOTES AND OPERATION
=============================================================================

STARTUP PROCEDURE:
1. Ensure encoder is connected and powered
2. Verify card supply loaded
3. Select Auto or Manual mode
4. Press START_BTN
5. System will prepare card to tip automatically
6. Ready indicator illuminates when ready
7. Run paper/base mechanism
8. System feeds card when paper detected and position reached

CALIBRATION:
1. Measure distance from start sensor to feed point
2. Calculate encoder counts needed (see HARDWARE_SPECS.md)
3. Update D2 with calculated value
4. Run test cycle at slow speed
5. Measure actual card placement
6. Adjust D2 until placement is accurate
7. Test at full production speed
8. Fine-tune as needed

ADJUSTMENT:
- To feed EARLIER: Decrease D2 (FEED_DELAY_COUNTS)
- To feed LATER: Increase D2 (FEED_DELAY_COUNTS)
- Change D2 in increments of 50-100 counts
- Test after each adjustment

ALTERNATIVE TIME-BASED MODE:
- If encoder sync not desired, use timer-based trigger
- Add input 0.12 to select delay mode
- Adjust TIM005 preset based on belt speed
- Less accurate but simpler

SINGLE CARD ENFORCEMENT:
- FEED_IN_PROGRESS flag prevents re-trigger
- Card must reach tip before next cycle
- PAPER_DETECTED flag cleared after each feed
- Position comparison only triggers once per detection

=============================================================================
TROUBLESHOOTING
=============================================================================

PROBLEM: Card feeds too early
SOLUTION: Increase D2 (FEED_DELAY_COUNTS) by 50-100

PROBLEM: Card feeds too late
SOLUTION: Decrease D2 (FEED_DELAY_COUNTS) by 50-100

PROBLEM: Encoder count not changing
SOLUTION: Check encoder wiring (A, B phases), verify power, check cable

PROBLEM: Card doesn't reach tip
SOLUTION: Check card jam, verify motor operation, check stop sensor alignment

PROBLEM: Multiple cards feeding
SOLUTION: Verify W0.06 logic prevents retrigger, check card separation

PROBLEM: Start sensor not detecting paper
SOLUTION: Check sensor alignment, clean lens, verify output wiring

PROBLEM: Inconsistent feeding at high speed
SOLUTION: Reduce max speed, check encoder signal quality, verify scan time

PROBLEM: System faults immediately
SOLUTION: Verify encoder connected, check wiring

=============================================================================
TESTING CHECKLIST
=============================================================================

□ Encoder counts correctly (check D0 value increases as base moves)
□ Encoder direction correct (counts up when paper moves forward)
□ Start sensor detects paper reliably
□ Stop sensor detects card at tip
□ Card feeds to tip automatically when needed
□ Feed triggers at correct position
□ Card placement accurate at slow speed
□ Card placement accurate at full speed
□ Fault reset procedure works
□ Manual mode operates correctly
□ Auto mode operates continuously
□ Cycle counter increments
□ No double-feeding occurs
